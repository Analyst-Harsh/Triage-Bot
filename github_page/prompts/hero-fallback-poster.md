particles/points in a gradient from violet (#7C3AED) through indigo (#6366F1)
to blue (#60A5FA) — like a long-exposure photo of drifting light. Some
particles sharp/bright in the foreground, more diffuse and dim in the
background for depth. No recognizable shapes, no text, no logos, no human
figures.

Composition: avoid a busy focal point dead-center — headline text will sit on
top of the left/center of the frame, so keep that region calmer/darker than
the edges.

Export: optimized JPG or WebP (this is a fallback asset, not the primary
hero — file size matters more than for a hero the user will actually watch
