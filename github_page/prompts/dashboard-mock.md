A polished, modern operator-dashboard UI screenshot (demo/concept — fake data,
not a real product) for an AI GitHub-issue-triage system called "Triage Bot".

Style: dark mode, deep slate-navy background (#0F172A), glassmorphism panels
with soft borders, violet-to-blue gradient accents (#7C3AED to #60A5FA),
JetBrains-Mono-style monospace for numbers/labels, Inter for other text.

Layout:
- Top row: 4-5 rounded glass status tiles, each a run-status count (e.g.
  "Pending Approval", "Auto Posted", "Researching", "Failed"), bold monospace
  number, colored left-accent bar (green = low-risk/auto-posted, amber =
  pending/medium-risk, red = failed/high-risk).
- Below: a paginated table/list of recent runs with columns for repo name,
  issue title, a color-coded status pill, estimated cost, and duration. Use
  realistic but entirely fictional GitHub repo/issue names — never real
  project names.
- Small colored risk dot (green/amber/red) per row.

Finish: clean, readable, high information density but not cluttered, subtle
grid lines, one hover-highlighted row. Rendered as a crisp screenshot inside a
plain rounded-corner card or minimal browser chrome (no OS chrome, no
distracting background). Professional SaaS-dashboard aesthetic (Linear/
Vercel/Retool-style). No people, no stock photography, no watermarks, no real
company/project names anywhere in the mock data.
